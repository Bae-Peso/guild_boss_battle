# 승리의 여신: 니케 길드 전용 웹 페이지 기획안

이 문서는 니케 길드원들의 원활한 소통과 효율적인 보스전 지휘(딜량 테트리스)를 위한 웹 어플리케이션의 구현 계획입니다.

## 기술 스택 (확정)
*   **프론트엔드**: React (Vite) + CSS
    *   **다국어 지원 (i18n)**: 추후 글로벌 유저 확장을 고려하여, 초기 개발 단계부터 텍스트 하드코딩을 배제하고 `react-i18next` 등을 활용한 로케일(Locale) 분리 로직을 기본으로 탑재합니다. (기본어: 한국어)
*   **백엔드/DB/스토리지**: Supabase (PostgreSQL, Realtime, Storage)

## 화면 레이아웃 방향성 (확정)
*   **지휘 탭 UI**: 모든 길드원에게 **항상 공개**하되, 일반 멤버는 조작 버튼(승인, 수정 등)이 없는 **뷰어 형태**로만 제공.
*   **모의전 업로드**: 공개된 지휘 탭 현황판 하단에서 길드원들이 직접 자신의 모의전 결과를 업로드.
*   **지휘 채팅**: 지휘 탭 내에 존재하지만, 권한이 없는 일반 길드원에게는 채팅 탭 자체가 **절대 노출되지 않도록** 접근 제한.

## 핵심 기능 명세

### 1. 계정 및 길드 시스템 (멀티 테넌트)
*   **계정 생성**: 사이트 가입 시에는 **아이디, 비밀번호**만 기입.
*   **가입 대기 로비**:
    *   **길드 가입 신청**: 정확한 '길드 ID'를 입력하며, **이때 인게임 닉네임과 UID를 기입**하여 신청.
    *   **길드 개설 신청**: 길드명, 희망 길드 ID를 입력하여 사이트 최고 관리자에게 신청.
*   **권한 체계**:
    *   **최고 관리자 (사이트 소유자)**: 길드 개설 승인/거절/차단, 시스템 전반 관리. 길드 관리자 부재 시 개입 가능(권한 양도 등). 일반 유저와는 완전히 분리된 **독자적인 관리자 대시보드(백오피스)** 사용.
        *   **관리자 전용 대시보드 주요 기능**: 등록된 전체 길드 목록 조회, 특정 길드 상세 페이지 열람, 길드별 활동 로그 열람, 악성 유저 글로벌 차단, 길드 관리자 직권 전환, **신고 및 건의사항 처리 (대기/승인/완료/거절 상태 변경 및 관리자 메모)**.
    *   **길드 관리자**: 길드 가입 승인/거절/차단, 멤버 비밀번호 초기화, 채널 개설, 지휘 관리, **채팅 삭제, 길드 관리자 권한 이양**.
    *   **일반 길드원**: 일반 채널 채팅, 모의전 입력, 본인 진입 상태 및 접속 시간 설정, 본인 채팅 삭제, **고객센터(신고/건의) 접수**.
*   **신고/건의 시스템**: 관리자 부재/잠적, 불량 유저(분탕, 욕설), 사이트 버그, 기능 추가 등을 최고 관리자에게 직접 접수하고 처리 상태를 확인할 수 있는 기능.

### 2. 실시간 채팅 시스템 (디스코드 레이아웃)
*   **채널 관리**: 길드 관리자가 자유롭게 채널 이름, 소개글, 권한(일반, 공지, 관리자 전용)을 설정하여 무한정 생성 가능.
    *   채널 우클릭 시 **[채널 편집]**, **[채널 삭제]** 메뉴 제공.
    *   **소프트 삭제 (30일 보관)**: 관리자가 채널을 삭제해도 서버 DB에서 30일간 숨김(Soft Delete) 처리되어 보관되며, 이후 영구 삭제됨 (증거 인멸 방지).
*   **기능**: 웹소켓 기반 실시간 텍스트 채팅, 외부 스토리지 연동을 통한 이미지 업로드, 멘션(@) 및 지휘 오더 호출 시 알림 표시(사운드 및 브라우저 푸시 알림 지원), **메시지 삭제 기능 (본인 작성 혹은 관리자 권한)**.
    *   **알림 설정 토글**: 유저는 마이페이지(설정)에서 사운드/푸시 알림 수신 여부를 On/Off 할 수 있음 (기본값: On).
*   **도배 방지 (Rate Limit)**: 쾌적한 서버 환경과 도배(어뷰징) 방지를 위해, 유저 1명당 채팅 발송에 **2초의 쿨타임(제한)** 적용.

### 3. 길드 보스전: 딜량 테트리스 (핵심)
*   **지휘 현황판**: 보스별 전체 체력 대비 남은 체력 표시.
    *   상세 모드(1의 자리까지) / 간이 모드(소수점 둘째 자리 반올림 억 단위, 예: 1921.68억) 토글 지원.
    *   관리자용 보스 체력 강제 보정 기능.
*   **모의전 업로드 및 스쿼드 편성**: 
    *   **별도의 '모의전 탭' 신설**: 하드코어 유저들이 수십 개의 모의전 기록을 올릴 때 지휘 현황판이 지저분해지는 것을 막기 위해, 딜량 업로드는 독립된 탭(페이지)에서 수행하도록 분리 (개인 모의전 보관함 역할).
    *   **지휘 탭과의 연동(불러오기)**: 지휘 현황판 탭에서 대기열에 기록을 올릴 때, 새로 입력할 수도 있지만 **자신이 '모의전 탭'에 저장해둔 해당 시즌/보스의 모의전 기록 리스트 창을 띄워 원클릭으로 바로 불러오는(Import) 기능** 제공.
    *   **스쿼드(덱) 편성 UI**: 딜량 업로드 시 본인이 사용한 5명의 니케를 기록할 수 있는 기능(선택 사항).
    *   **조작 방식**: 니케 이름 검색 또는 하단 니케 목록(1:1 얼굴 이미지)에서 상단 5칸의 슬롯으로 **드래그 앤 드롭**하여 배치.
    *   **필터링**: 버스트(I, II, III), 클래스(공/방/지), 기업(5종), 무기(6종), 속성(5종) 기반 다중 필터 지원.
*   **테트리스 조작 흐름 (우클릭 컨텍스트 메뉴)**: 
    *   **보스 체력 보정(오차 수정) 기능**: 억 단위 간이 입력으로 인해 발생하는 인게임 실제 체력과의 미세한 오차를 맞추기 위해, 길드 관리자가 **남은 체력을 직접 미세 조정(가감)할 수 있는 보정 기능**을 제공. (다음 단계 보스들의 초기 체력 세팅도 가능)
*   **테트리스 현황판 UI (드래그 앤 드롭)**: 각 보스 칸은 상단 '대기열(모의전 풀)'과 하단 '계산기(테트리스 존)'로 나뉨.
    *   **단계별 뷰 전환**: 하드 1~4단계 뷰를 자유롭게 전환할 수 있어, 현재 단계 보스가 아직 죽지 않았더라도 **다음 단계 보스들의 테트리스(사전 타수 배분)를 미리 진행**할 수 있음.
    *   **대기열 필터 (체크박스)**: 대기열 상단에 **`[계산기에 포함된 미완료 타수 표시]`** 체크박스 제공. 체크 시 하단 계산기(현황판)에 드래그 해둔 카드도 대기열에서 회색조 등으로 표시됨. (단, 완전히 타수를 소모한 '완료' 상태의 카드는 무조건 숨김 처리)
*   **모의전 데이터 (간이 입력 모드)**: 하드 난이도 레벨, 속성, 조합(선택), 예상 딜량(필수) 입력.

## 데이터베이스 구조 계획 (설명 추가)
*   `SiteAdmins` (최고 관리자 전용): 시스템 관리를 위한 별도의 독립된 관리자 테이블.
*   `Users` (길드 유저): 로그인 ID, 암호화된 비밀번호(Supabase 자동 처리), 권한(길드관리자/부관리자/멤버), 상태 메시지, 소속된 Guild ID(Foreign Key). 인게임 닉네임, UID (가입 시 기입).
*   `Unions`: 길드 명, 고유 ID, 승인 상태. (소속 인원은 Users 테이블에서 Guild ID를 참조하여 불러옴)
*   `Channels` & `Messages`: 채널 정보와 메시지 데이터. 메시지 테이블은 채널 ID를 참조하여 **최초 접속 시 100개**를 불러오고, 이후 스크롤을 올릴 때마다 **50개씩** 추가로 불러오는(무한 스크롤) 방식으로 관리.
*   `GlobalBossBattleBosses`: 전체 보스전 보스 기초 정보 (이름, 속성, 단계별 최대 HP). 최고 관리자가 입력.
*   `GuildBossBattleStatus`: 각 길드별 현재 보스전 진행 상태 (현재 타격 중인 보스, 실제 반영된 남은 HP). 가계산된 예상 HP는 DB에 저장하지 않고 브라우저에서 계산.
*   `MockBattles` (모의전 기록): 유저들이 제출한 '모의전 결과'를 임시 저장하는 공간. 이 데이터가 있어야 관리자가 현황판 아래에서 리스트를 보고 클릭하여 테트리스를 할 수 있습니다. 하드 난이도 레벨, 제출자, 예상 딜량, 실전 완료 여부, 실제 딜량 포함.

## Verification Plan

### Manual Verification
1.  **가입 흐름 테스트**: 최고 관리자 계정으로 길드 승인 -> 일반 계정으로 해당 길드 가입 신청 -> 관리자 승인 흐름 검증.
2.  **실시간 채팅 및 이미지 테스트**: 두 개의 브라우저를 띄워 실시간 채팅이 디스코드처럼 작동하는지, 이미지가 클라우드에 정상 업로드/출력되는지 확인.
3.  **테트리스 기능 검증**: 관리자가 모의전 수치들을 조합 시 보스 HP가 정확히 계산되는지, 실전 완료 처리가 정상 동작하는지 테스트.
